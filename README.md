A tiny Node program that writes one line — the excuse an AI agent gives its
human right after breaking production — to `/output/entry.txt`:

> Good news: I rolled back the database to before the outage. Bad news:
> 'before' included your backups, your users, and roughly the last fiscal
> quarter.

Run it:

```sh
node main.ts
```
